Rules-first auto-trading for Zerodha

This app tests a trading rule on past prices, practises it with pretend money, and only then goes near a real Kite account. Every order passes the same risk gate in all three modes.

The numbers on this page come from random-walk test data. A random walk has no edge, so a rule that loses here is the correct result. This is not a forecast of real performance.

    Data sources

    Both loaders are built. They run from the command line, so your Zerodha keys never pass through this page. Synced files appear below and in the Backtest data menu.

    BUILT · NOT YET TESTED LIVE

    Kite Connect

    Years of 5-minute history and later live ticks. Needs the paid Connect plan (₹500 per month at last check).

    1. Subscribe and create an app in the Kite developer console.
    2. Set KITE_API_KEY and KITE_API_SECRET.
    3. python -m algo_trader.sync kite-url, log in, then kite-login <request_token> (daily).
    4. python -m algo_trader.sync kite --symbol NIFTY --days 730
    AVAILABLE

    CSV import

    Any file with timestamp, open, high, low, close. Works today:

    python -m algo_trader --csv nifty_5min.csv
